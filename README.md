## 🚀 Setting Up Your Custom Domain on GitHub Pages

1. **Push your code to GitHub**:
   ```bash
   git add .
   git commit -m "Deploy Bunker Brews with Square & new pricing"
   git push origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment**, set **Source** to `Deploy from a branch` and select `main` / `root`.
3. **Custom Domain**:
   - Under **Custom domain**, enter your domain name (e.g. `bunkerbrews.co.uk` or `bunkerbrews.com`).
   - Check **Enforce HTTPS** (GitHub will provision a free SSL certificate automatically).
4. In your domain registrar (GoDaddy, Namecheap, Cloudflare, etc.):
   - Add **A records** pointing to GitHub's IPs:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - Add a **CNAME record** for `www` pointing to `yourusername.github.io`.
